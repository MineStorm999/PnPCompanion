# PnPCompanion
## Features
- Rulesystem
    - Node:
        - Name
        - Description
          - can have html and markdown
          - add "links" to other rules in the system: `{OtherRule}` it then gets converted to a link. links display the linked rule as tooltip (name & description)
          - Scroll to Node on click
    - Editable
